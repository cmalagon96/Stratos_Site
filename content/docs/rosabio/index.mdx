# RosaBio

RosaBio is a cloud-native pipeline orchestration platform for genomic research.
It eliminates manual intervention between pipeline stages and provides a
"context layer" (similar to Redux) that carries state across ROSA → SPLASH → P2G
and related workflows.

## Architecture

RosaBio runs on AWS Batch with Docker containers. The orchestration engine:

1. Monitors job completion events via EventBridge
2. Extracts output paths and injects them as inputs to downstream stages
3. Handles retry logic, failure notifications, and cost tracking
4. Provides a web dashboard for pipeline status and log streaming

## Supported Pipelines

| Pipeline | Description |
|---|---|
| ROSA | RNA-seq alignment and quantification |
| SPLASH | Unsupervised splicing detection |
| P2G | Peak-to-gene linkage for ATAC-seq |
| DNA Methylation | Bisulfite sequencing analysis |

## Getting Started

### Prerequisites

- AWS account with Batch, S3, and ECR access
- Docker installed locally for custom container builds
- NIH dbGaP authorisation (if processing controlled-access data)

### Configuration

Pipeline configurations are defined as JSON manifests stored in S3. Each manifest
specifies the container image, input paths, resource requirements, and downstream
pipeline to trigger on completion.

```json
{
  "pipeline": "rosa",
  "input_bucket": "s3://my-genomics-bucket/raw",
  "output_bucket": "s3://my-genomics-bucket/processed",
  "instance_type": "r5.4xlarge",
  "vcpus": 16,
  "memory_gb": 128,
  "on_success": "splash"
}
```

## Security

RosaBio is designed for HIPAA and NIH dbGaP compliance:

- All data encrypted at rest (S3 SSE-KMS) and in transit (TLS 1.3)
- VPC-isolated Batch compute environments
- IAM roles with least-privilege access
- CloudTrail audit logging for all data access
